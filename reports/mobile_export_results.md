# Проверка мобильного экспорта

## Решение

Для интеграционного теста используется **FP32 MobileNetV3-Small**.
Статический INT8 не прошёл проверку качества и исключён из индекса выпуска.
Исходные веса, данные и пороги успешного FP32-выпуска не изменены.

| Метрика | FP32 | INT8 |
|---|---:|---:|
| Val Accuracy, 191 фото | 81.68% | 5.24% |
| Val Macro-F1 | 79.15% | 0.43% |
| Test Accuracy, 185 фото | 84.32% | Не оценивался после провала val |
| Test Macro-F1 | 82.51% | Не оценивался после провала val |
| Размер | 5.99 МиБ | Около 1.86 МиБ |
| Выпуск для интеграционного теста | Да | Нет |

## Наблюдение → интерпретация → действие

1. **FP32:** top-1 совпадает с Python на всех 1 522 контрольных кадрах,
   максимальная ошибка logits около 0.0000711 → экспорт сохранил поведение
   классификатора → передать FP32 разработчику для Android-проверки.
2. **INT8:** 181 ошибка из 191 на val, Macro-F1 около 0.004326 → текущая
   статическая квантизация даёт неприемлемое поведение; точная причина ещё
   не установлена → не использовать этот FlatBuffer, не ослаблять quality gate.
   Для следующего эксперимента проверить промежуточные активации и операции,
   затем рассмотреть FP16 или квантование только весов как отдельные варианты.
3. **Runtime:** XNNPACK не запускает INT8, builtin CPU запускает → проблема
   совместимости ускорителя отделена от потери качества → не обещать скорость
   INT8 и не переносить настройки Linux на Android без проверки.
4. **Отказ FP32:** external FPR на negative_test = 1/573 ≈ 0.17%, при этом
   правильное подтверждение = 22/185 ≈ 11.89% → порог слишком строг для удобного
   продуктового сценария → отдельно согласовать и проверить компромисс отказов
   и ложных подтверждений на новых телефонных фотографиях.
5. **Данные:** существующий test уже использовался → это диагностический
   результат → собирать отдельный независимый полевой test.

## Пакет

`.runtime/mobile_export_result_v3/public/` содержит индекс только с FP32
и версионированную папку с моделью, маппингом, preprocessing, policy,
синтетическими контрольными ответами и SHA-256 в манифесте.
INT8 находится только в приватной рабочей папке, не в public-пакете.
Для передачи собран `.runtime/nevidal-mobile-fp32-2026-10-30-v1.zip`:
8 файлов, без фотографий и checkpoint. Рядом сохранён SHA-256 архива.
Проверки упаковки и обработки I/O: 15 тестов прошли.

Статус: **кандидат для интеграции**, не production-ready. Остались проверка
на Android (скорость, RAM, численные ответы и работа offline), проверка SDK-ID
2GIS, включая отдельный ID арки главного входа, и настройка приемлемой частоты
отказов. Публикация на хостинг не выполнялась.
